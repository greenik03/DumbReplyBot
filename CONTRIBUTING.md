Here are some things to look out for, if you decide to contribute to this repository:

# AI / LLM Usage
This project has not been touched by an LLM, and I expect any and all contributions to follow suit. \
I encourage anyone wanting to work on this to solve any issues or create new features by themselves and not rely on LLMs to do that job for them (and to not give the AI companies any money, I would like to afford RAM again). \
**If I suspect that a PR is AI-generated or has some amount of AI-generated code, it will be automatically rejected**. No exceptions. Same goes for issues.

# Issues
When reporting bugs, please make sure that they are reproducible and include as much detail as possible on how to reproduce them. \
When suggesting new features, it is recommended (though not required) to explain why a feature should be implemented.

# Pull Requests
Code contributions in pull requests should be in their own branch. The code should be tested to make sure it works as intended before opening a PR. The code may be tested again before merging into the main branch. Commit messages should be descriptive of the changes made.
